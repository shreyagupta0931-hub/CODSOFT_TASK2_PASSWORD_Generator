# CodSoft Python Programming Internship - Task 2

## Password Generator

A simple command-line Password Generator developed using Python as part of the CodSoft Python Programming Internship.

## Features

- Generate random passwords
- User can choose password length
- Uses letters, numbers, and special characters
- Easy to use command-line interface
- Random password generation

## Technology Used

- Python
- random module
- string module

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open `password_generator.py`.
4. Run the program using Python.
5. Enter the desired password length.
6. The program will generate a random password.

## Project Type

Command-Line Application (CLI)
